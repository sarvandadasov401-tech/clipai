CLIPAI Android başlangıç dosyaları

Bu paket, mevcut CLIPAI deposuna eklenecek ilk yerel Android uygulaması iskeletini içerir.

TELEFONDAN EKLEME:
1. ZIP dosyasını aç.
2. İçindeki mobile klasörünü GitHub deposunun ana dizinine yükle.
3. .github/workflows/build.yml dosyasını depodaki aynı yoldaki dosyayla değiştir.
4. Değişiklikleri main dalına kaydet.
5. GitHub deposunda Actions sekmesine gir.
6. Build CLIPAI Android APK iş akışının tamamlanmasını bekle.
7. Başarılı çalıştırmayı aç ve Artifacts bölümünden CLIPAI-debug-APK dosyasını indir.
8. ZIP'i telefonda açıp app-debug.apk dosyasını kur.

Bu ilk sürüm yalnızca Android uygulamasının temelini ve galeriden video seçmeyi sağlar. Henüz video kesmez, AI analizi/altyazı/YouTube içe aktarma yapmaz. Bunlar sonraki geliştirme adımlarıdır.

Derleme GitHub Actions'ın ücretsiz kullanım kotasına bağlıdır. GitHub kotası aşılırsa ek ücretli kullanım açma; önce kotanın yenilenmesini bekle.
